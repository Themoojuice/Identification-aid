# Identification aid robustness review — 2026-10-07

## Verdict and scope

Several reproducible defects were corrected in scientific inference, session recovery, offline package isolation and the private preview server. The application remains a research prototype suitable for controlled evaluation, not an independently validated identification authority. This review did not publish or deploy the changes.

The handoff, audit and eleven supplied packets informed the review. Immutable packets, Lucid scores and archived source records were not edited. All 36 source-audit issues remain open; checking their presence and policy metadata does not resolve them or constitute a behavioural test for every issue.

## Species policy v2

The versioned interpretation is `selective-species-conservative@2`, in scientific package `review-species-2026-10-07`. This supersedes the original Stage 7 claim that all five outcomes are currently usable.

- Unknown sex or maturity now pauses saved scope-dependent species evidence instead of allowing it to contribute support. Juvenile restrictions remain in force.
- Source-uncertain hints are limitations, not positive diagnostic evidence. Regression SP0011 demonstrates that the warning about female identifiability cannot support an identification.
- Microscopy and female genital-preparation requirements now govern scored matches and disagreements, not just which questions are displayed. Answers are retained while unavailable evidence is paused.
- Tentative-only evidence and mixed agreements/disagreements are capped conservatively.
- `strong_candidate` is withheld until a reviewed comparison scope is encoded. Counting two profiles within a genus did not establish adequate comparison against unprofiled species. SP0005 reproduced an unjustified strong result from limited female external evidence; the replacement regression prevents it. There are 32 selective profiles and 195 other unscored placements, not a comprehensive species key.
- Possible, plausible and conditional diagnostic guidance remain available. Diagnostic-if-confirmed is a request for confirming evidence, not a confirmed identification. SP0008's angle/lighting limitations and all thesis-only nomenclatural qualifications remain visible.

These are conservative derived-policy corrections, not alterations to the source's biological assertions. Species suggestions remain optional and cannot change genus ranking.

## Schubert evidence

Policy `schubert-source-uncertainty@3` excludes unknown/not-applicable assertions from positive scoring and question utility. SC030_K previously supplied tentative support for Saitis from a statement that it was not adequately diagnosed; the regression now requires an unscored result. Missing assertions remain unscored, not absent.

Applicable Schubert questions remain manually selectable even when historical Lucid routing does not prioritise their concepts. Their independent evidence path must not be hidden by the incomplete crosswalk. All 123 assertions remain preserved.

## Reliability fixes

- Imported sessions are validated for structure, state ownership, duplicate observations, specimen references, species-hint references and published-key history before replacing current work.
- Malformed legacy records are retained as non-scoring recovery history rather than crashing or becoming evidence. Invalid saved copies are retained for export while the newest valid backup is restored. Missing old timestamps do not outrank genuinely newer work.
- Local-storage failures no longer crash startup. Serialized IndexedDB writes prevent older asynchronous saves from overwriting newer work; failed persistence prompts export rather than falsely confirming a successful manual save.
- Version metadata is not an executable historical engine. Older imports now warn that the loaded package evaluates their evidence, and exports distinguish original pins from the package loaded at export. Exact historical replay is not implemented.
- Offline updates serialize within a worker. Tabs bind to their own complete core package so a later activation does not silently replace an already-open tab's scientific data. Missing required pinned assets fail explicitly. If browser package storage fails, online navigation can fall back to the network.
- The private preview server survives malformed URLs and rejects encoded traversal outside each allowed asset root.

## Verification

- Source/foundation suite: 32 tests passed, including original packet hashes, exact Lucid reconstruction and deterministic compilation.
- Application suite: 109 tests passed with one worker, including the new scientific/session/storage regressions and exhaustive option-illustration rendering checks. Concurrent workers produced timeouts in two large image checks on this host, not failed assertions. The standard application test command now uses one worker; assertions and timeouts are unchanged.
- Worker runtime tests execute the actual service-worker code in a controlled harness: bad hashes preserve the previous package, storage denial falls back online, old/new clients remain on their own data, and a missing pinned asset fails explicitly. These are not a live physical-browser two-version rollout/rollback test.
- Production compilation, TypeScript, offline-package construction and verification passed during the review.
- Browser smoke checks on the isolated local origin confirmed neutral abstentions, adult-male Schubert manual reachability and distinct crescent-band state guides. Further final-run results are recorded in STATUS.md.

Source-derived tests establish consistency with the supplied records and intended logic. They cannot establish accuracy on unknown real spiders. No percentage accuracy claim is supported.

## Remaining priorities

Cape York photographs are useful trials, but uncertain labels must not be treated as ground truth. Measure genus shortlist coverage, false confident outputs and cases outside the represented source.
2. Have a salticid specialist review diagnostic interpretations, schematic anatomy and the 36 open source issues. Rendering every option does not prove every illustration biologically adequate.
3. Exercise saved-session recovery, low storage, offline use and actual two-version upgrade/rollback on physical phones; run assistive-technology and lower-end-device checks.
4. Encode reviewed species comparison scopes before re-enabling strong species outcomes. Review separate qualifying publication evidence before changing thesis-only name qualifications.

Archived-media rights remain unresolved and private media remain excluded from distributable packages. No new media licence assumption, dependency upgrade, raw-source extraction or taxonomic correction was made.
